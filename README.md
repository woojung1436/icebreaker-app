# 아이스브레이킹 카드 뽑기

기업 교육 오프닝용 질문 카드 뽑기 앱. 진행자는 큰 화면(노트북/빔프로젝터)을 띄우고, 참가자는 각자 폰으로 QR을 스캔해 질문 카드를 뽑습니다.

## 로컬에서 실행하기

```bash
npm install
npm run dev
```

- 진행자 화면: `http://localhost:5173/host`
- 서버는 `4000` 포트에서 실행됩니다.

## 실제 교육장에서 쓰는 방법 (같은 와이파이)

1. 강사 노트북에서 `npm run dev` 실행
2. 노트북의 로컬 IP 확인 (터미널에 `Network:` 로 Vite가 출력해줌, 예: `http://192.168.0.12:5173`)
3. 노트북에서 `http://<로컬IP>:5173/host` 접속 → 빔프로젝터에 띄우기
4. 참가자들은 같은 와이파이에 연결한 뒤, 호스트 화면의 QR코드를 스캔해서 입장
   - 클라이언트는 자동으로 접속한 주소의 호스트명을 기준으로 서버(4000번 포트)를 찾으므로 별도 설정이 필요 없습니다.

와이파이가 불안정하거나 외부에서도 접속해야 한다면 `server`를 Render/Railway 같은 상시 구동 Node 호스팅에 배포하고, `client/.env`에 `VITE_SERVER_URL=https://your-server.example.com`을 설정한 뒤 `client`를 Vercel/Netlify 등 정적 호스팅에 배포하세요.

## 질문 카드 수정하기

`server/src/questions.ko.json` 파일을 열어 `id`/`text`를 자유롭게 추가·수정·삭제하면 됩니다. 서버 재시작(`npm run dev`) 후 반영됩니다.

## 조 편성 & 응답 대시보드

- 참가자는 입장 직후 원하는 조를 직접 선택합니다 (버튼마다 실시간 인원수 표시). 언제든 "변경" 버튼으로 다른 조로 옮길 수 있고, 본인 화면에는 같은 조 멤버 닉네임이 표시되어 물리적으로 모여 앉기 쉽습니다.
- 진행자 화면 좌측 "조 편성"에서 조 개수를 바꿀 수 있고(적용), 조 개수를 줄이면 범위를 벗어난 인원은 자동으로 "미배정"으로 표시됩니다. "조 다시 섞기"는 모든 인원(참가자가 직접 고른 조 포함)을 한 번에 무작위로 재배정하는 진행자 전용 기능입니다.
- 참가자는 카드를 뽑은 뒤 답변을 입력해 제출하면, 진행자 화면에 조별로 묶인 카드에 실시간으로 답변이 표시됩니다 (제출 후에도 "수정하기"로 답을 바꿀 수 있습니다).
- 개별 답변 내용은 진행자 화면에만 표시되고, 참가자끼리는 서로의 답변을 볼 수 없습니다 (조 멤버 명단만 공유됨).

## AI 실시간 요약 (Claude API)

참가자들의 답변이 쌓이면 Claude가 전체 분위기 요약, 핵심 키워드, 특히 눈에 띄는 답변을 자동으로 뽑아 진행자 화면 상단에 실시간으로 보여줍니다. 강의를 시작하기 전 "우리 팀은 이런 분위기네요" 하고 짧게 멘트를 치는 데 활용할 수 있어요.

**설정 방법**

1. [console.anthropic.com](https://console.anthropic.com)에서 API 키를 발급받습니다.
2. `server/.env.example`을 복사해 `server/.env`를 만들고 키를 채워 넣습니다.
   ```bash
   cp server/.env.example server/.env
   # server/.env 파일을 열어 ANTHROPIC_API_KEY=sk-ant-... 입력
   ```
3. 서버를 재시작하면(`npm run dev`) 진행자 화면 상단 "AI 실시간 요약" 패널이 활성화됩니다.

**동작 방식**

- 참가자가 답변을 제출하면 4초 뒤 자동으로 요약이 갱신됩니다 (연속으로 답변이 들어오면 마지막 제출 기준으로 다시 4초 대기 — API 호출을 과도하게 늘리지 않기 위함).
- 진행자는 "지금 다시 요약" 버튼으로 언제든 즉시 갱신할 수 있습니다.
- API 키가 없으면 이 패널에는 안내 문구만 표시되고, 나머지 기능(카드 뽑기/조 편성 등)은 평소대로 동작합니다.
- 요약에 사용되는 답변 내용은 Anthropic API로 전송됩니다 — 민감한 정보를 다루는 조직이라면 참가자에게 사전 안내하세요.

## 클라우드에 배포하기 (Render)

와이파이/로컬 네트워크에 의존하지 않고 어디서든 접속 가능한 고정 URL로 쓰고 싶다면 Render에 배포하세요. 저장소 루트의 `render.yaml`이 서버(Node 웹 서비스)와 클라이언트(정적 사이트) 두 개를 한 번에 정의해둔 "Blueprint"입니다.

1. **GitHub에 코드 올리기** — 이 프로젝트는 이미 git 저장소로 초기화되어 있습니다. GitHub Desktop(무료, 설치형 GUI) 같은 도구로 로그인 후 "Publish repository"만 누르면 새 저장소가 만들어지고 코드가 올라갑니다.
2. **Render 가입** — [render.com](https://render.com) 에서 Google 계정 등으로 가입 (신용카드 불필요).
3. **Blueprint로 배포** — Render 대시보드에서 New + → Blueprint 선택 → 방금 올린 GitHub 저장소 연결 → `render.yaml`을 자동 인식해서 `icebreaker-server`(웹 서비스)와 `icebreaker-client`(정적 사이트) 두 서비스가 한 번에 생성됩니다.
4. **환경변수 설정**
   - `icebreaker-server` 서비스 → Environment → `ANTHROPIC_API_KEY` 값 입력
   - `icebreaker-server` 배포가 끝나면 URL이 생깁니다 (예: `https://icebreaker-server.onrender.com`)
   - `icebreaker-client` 서비스 → Environment → `VITE_SERVER_URL`에 위 서버 URL 입력 → 저장하면 클라이언트가 재빌드되며 반영됩니다
5. **접속 확인** — `icebreaker-client`의 URL(예: `https://icebreaker-client.onrender.com`)이 실제 서비스 주소입니다. `/host`를 붙여서 진행자 화면을 열면 됩니다.

**무료 플랜 주의사항**: Render 무료 웹 서비스(서버)는 15분간 요청이 없으면 슬립 상태가 되고, 다음 요청 때 다시 깨어나는 데 30~60초가 걸립니다. 실제 교육 세션 **시작 5~10분 전에 서버 URL(`/health`)을 한 번 미리 열어서 깨워두세요.** 자주 쓸 예정이라면 Render의 유료 Starter 플랜(월 $7)으로 올리면 이 지연이 없어집니다.

## 진행 팁

- 진행자 화면의 "덱 리셋 / 새 라운드" 버튼을 누르면 모든 참가자의 카드와 답변이 초기화되어 다음 세션에 재사용할 수 있습니다 (조 배정은 유지됩니다).
- 같은 방 안에서는 질문이 중복 배정되지 않습니다 (질문을 모두 소진하면 자동으로 다시 섞어서 재사용).
- 참가자가 새로고침해도 이미 뽑은 카드와 제출한 답변은 유지됩니다.
